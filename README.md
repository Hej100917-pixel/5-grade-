# 학점제 내신 내비게이터 (Grade-Up Predictor)

고교학점제 5등급제 성적(등급·석차·수강자 수·원점수)을 9등급제 소수점 환산 등급으로 바꾸고, 과거 9등급제 입결과 비교해 **안정 / 적정 / 상향 / 위험**을 판정하는 웹앱입니다. 남은 학기 성적 시나리오(상향 곡선)를 조작하면 판정이 바로 바뀝니다.

> 저장소에는 아직 실제 입결이 들어 있지 않습니다. 화면의 **예시 데이터**는 가상의 대학이고, 실제 입결은 아래 방법으로 넣습니다. 판정은 참고용 추정치입니다.

## 실행

설치가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다. 입력한 성적은 그 브라우저에만 저장됩니다.

테스트: `node tests/engine.test.js`

## 화면 구성

| 단계 | 내용 |
|---|---|
| Step 1 현재 위치 진단 | 과목별 입력 → 상위 %, 9등급 환산 등급, 근거(트랙·신뢰도) / 전과목·국영수사과·국영수사·국영수과·전공 관련 평균 |
| Step 2 상향 곡선 조작 | 시나리오(현재 유지 / A 안정 상승 / B 전공 집중 / 직접 조정), 그래프 점 끌기, 학기별 교과 목표 등급과 목표 석차 |
| Step 3 대학 리스트 | 예상 최종 내신과 3개년 입결 비교, 70%컷 대비 차이와 판정, 행을 누르면 목표 역산 |

## 계산 방법

- **트랙 A (석차 있음, 최우선):** 상위 % = (중간석차 − 0.5) ÷ 수강자 수 × 100, 중간석차 = 석차 + (동석차 수 − 1) ÷ 2
- **트랙 B (원점수만):** Z = (원점수 − 평균) ÷ 표준편차 → 정규분포 상위 비율 → 입력한 5등급 구간(10/34/66/90%) 안으로 제한
- **트랙 C (등급만):** 5등급 구간 중간값 (신뢰도 낮음)
- **9등급 환산:** 상위 %를 9등급 구간(4/11/23/40/60/77/89/96%)에 넣고 구간 안에서 비례 계산. 예: 상위 5.2% → 2 + (5.2 − 4) ÷ 7 = 2.17등급
- **시나리오 A:** 교과별 상위 %를 매 학기 15%씩 줄임(P × 0.85ᵏ, 비율 조절 가능)
- **시나리오 B:** 전공 관련 교과만 3학년 1학기까지 상위 4% 이내로 단계적으로 진입
- **직접 조정:** 학기별 전체 평균 등급을 정하면 교과별 상위 %를 같은 비율로 조정
- **학교 유형 보정:** 자사고·특목고는 일반고 기준 상위 % = 우리 학교 상위 % × 보정계수로 대략 환산
  (기본값: 광역 자사고 0.75, 전국 자사고 0.55, 외고·국제고 0.6, 과학고·영재고 0.45 — 통계가 아닌 가정, 조정 가능).
  교과전형은 대학이 내신을 그대로 비교하므로 기본은 학종에만 적용
- **입결 합산:** 최근 3개년을 최근 연도부터 5:3:2로 가중 평균
- **판정:** 안정 ≤ 50%컷 < 적정 ≤ 70%컷 < 상향 ≤ max(70%컷 + 상향 범위 0.5, 추가합격 컷) < 위험.
  70%컷이 없으면 평균, 그다음 50%컷을 기준선으로 쓰고 표에 "평균 기준"처럼 표시합니다. 컷이 하나도 없으면 "입결 없음"
- **종합전형 보정:** 학기별 성적 상승 기울기(최대 0.15) + 전공 관련 교과 우수도와 성취도 A 비율(최대 0.15), 합계 최대 0.3등급. 교과전형에는 적용하지 않음
- **역산:** 남은 학기 필요 평균 = (목표 × 전체 가중치 − 지금까지 합) ÷ 남은 가중치 → 목표 석차 = 상위 % × 예상 수강자 수

## 실제 입결 넣기

학생부종합과 학생부교과 입결은 따로 관리합니다.

### 방법 1: 화면에서 CSV 불러오기 (이 브라우저에만 저장)

Step 3 아래 **입결 직접 불러오기**에서 CSV 파일을 고르거나 엑셀 표를 붙여 넣습니다. 한 줄에 대학·학과·전형유형·학년도 하나씩 적습니다.

```
대학,학과,구분,계열,전형유형,전형명,반영,학년도,50%컷,70%컷,추합컷,평균,출처
가나대학교,경영학과,문과,경영·경제,학생부종합,활동우수형,전과목,2026,2.10,2.45,2.90,,https://...
```

- 필수: 대학, 학과, 전형유형(학생부종합/학생부교과), 학년도
- 구분: 문과/이과 · 계열: 인문, 사회과학, 경영·경제, 교육, 자연과학, 공학, 의약·보건
- 반영: 전과목 · 국영수사과 · 국영수사 · 국영수과 (비우면 전과목으로 계산)
- 50%컷·70%컷·추합컷·평균 중 공개된 것만 채우면 됩니다.

### 방법 2: 저장소 데이터로 넣기 (모든 사용자에게 적용)

다른 AI에게 조사를 맡길 때는 [`docs/research-prompt.md`](docs/research-prompt.md)의 프롬프트를 쓰세요. 결과 CSV를 그대로 넣을 수 있습니다.

1. `data/research/`에 조사 결과(CSV 또는 JSON)를 넣습니다 (형식은 `tools/build_data.py` 참고).
2. `python3 tools/build_data.py`를 실행하면 `js/data-jonghap.js`, `js/data-gyogwa.js`와 엑셀용 `data/ipgyeol-*.csv`가 만들어집니다.
