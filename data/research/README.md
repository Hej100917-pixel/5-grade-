# 입결 조사 현황 (2024~2026학년도 수시)

조사일: 2026-10-18. 숫자는 모두 아래 공식 자료에서 옮겼고, 각 CSV 행의 `출처`·`비고`에 자료 주소와 쪽수(또는 공시 화면)를 적었습니다.
찾지 못한 값은 비워 두었고, 다른 학과·연도 값으로 채우거나 추정하지 않았습니다.

## 대상과 범위

- 대학 25곳: 서연고, 서성한, 중경외시, 건동홍, 국숭세단, 광명상가, KAIST·UNIST·GIST·DGIST
- 전형: 학생부종합·학생부교과 중 **일반 학생이 지원하는 전형 전부**
  - 뺀 전형: 기회균형·고른기회·농어촌·특성화고·재직자·특수교육·서해5도·사회배려 등 지원 자격이 정해진 전형,
    국방·위탁·취업자 등 특별전형, 해외고·검정고시 전형
- 모집단위: 대학이 공개한 모집단위 전부(학과 단위가 아닌 계열·학부 단위로 공개한 대학은 그 단위 그대로)

## 출처와 지표 (대학마다 정의가 다름)

| 대학 | 출처 | 지표 |
|---|---|---|
| 서울대, 연세대, 고려대, 서강대, 성균관대, 한양대, 중앙대, 경희대, 한국외대, 서울시립대, 국민대, 숭실대, 세종대, 단국대 | 대학어디가(adiga.kr) 대학정보 › 평가기준 및 입시결과 › 전년도 전형결과 (대학이 대교협에 공시한 값) | 최종등록자 학생부 **환산등급 50%·70%** |
| 광운대 | 입학처 수시 입시결과 PDF | 2025·2026: 최종등록자 70%컷(2026은 환산점수 기준 70% 학생) 등급, 2024: 최종등록자 평균. 모두 진로선택 제외 |
| 명지대 | 입학처 수시 입시결과 PDF | 최종등록자 평균·70%cut(환산점수 기준)·최저 등급 |
| 상명대(서울) | 입학처 수시 성적결과 PDF | 2025·2026: 최종등록자 평균·최저, 2024: 최종등록자 70%컷 |
| 가톨릭대 | 입학처 입시결과자료집 PDF(연도별) | 최종등록자 평균·최저 |
| 건국대, 동국대, 홍익대 (`건동홍.json`) | 각 대학 수시 입시결과 PDF(입학처·대학 공식 배포본) | 대표 학과 20개(문과 10·이과 10), 종합·교과 대표 전형 1개씩. 건국대 50%·70%컷, 동국대 평균·최저, 홍익대 평균·70%컷 (각 항목 sources에 쪽수) |

- CSV의 `추합컷` 칸은 대학이 "최저"로 공개한 값입니다(추가합격 마지막 등록자와 같다고 볼 수는 없음).
- adiga 공시의 "환산등급"은 대학마다 반영 교과와 진로선택 처리 방식이 달라 대학끼리 그대로 비교하기 어렵습니다.
- 광명상가 4곳은 adiga 공시값도 있으나, 학교 자료와 지표 정의가 달라 값이 대부분 다릅니다(예: 광운대 70%컷).
  두 지표를 한 행에 섞지 않으려고 학교 자료만 넣었습니다.

## 공개 자료가 없어 비워 둔 곳

| 대학 | 내용 |
|---|---|
| KAIST, UNIST, GIST, DGIST | 입학처에 전형별 경쟁률만 있고 합격자 내신 등급은 공개하지 않음 (KAIST 전형결과·UNIST 공지사항·GIST·DGIST 입학 홈페이지 확인) |
| 한국외대 학생부교과(학교장추천) | adiga 공시와 입학처 지원가이드 모두 "환산점수 70%"(1,000점 만점)만 공개, 등급은 미공개 |
| 서울대 학생부교과 | 해당 전형 없음 |
| 각 대학 일부 모집단위 | 등록 인원 3명 이하 등으로 대학이 공개하지 않음 |

## 보정

`overrides.json`에 원문 오류로 보이는 값을 사유와 함께 적어 계산에서 뺍니다. 현재 1건: 광운대 전기공학과
서류형 2026 70%컷(원문 1.00).

## 파일

- `{대학}-종합.csv`, `{대학}-교과.csv`, `건동홍.json`, `과학기술원.json`(모집단위만, 등급 미공개): 조사 결과. `python3 tools/build_data.py`로 프로그램 데이터(js/data-*.js)를 다시 만듭니다.
- 한 줄 = 대학·학과·전형·학년도 하나. 같은 학과라도 전형(예: 면접형·서류형)이 다르면 다른 행입니다.
